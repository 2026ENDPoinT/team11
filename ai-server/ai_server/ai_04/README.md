# AI-04 수면 부족 집계와 회복 기회

Spring 호출은 `POST /ai/v1/sleep-debt/calculate`이다. 일별 완료 수면과 목표를 집계하고, 설정과 미래 일정에 맞는 추가 수면 기회를 계산한다. [계산 흐름도](FLOW.md) · [백엔드 계약](../../docs/AI-04_BACKEND_CONTRACT.md) · [통합 백엔드 연동](../BACKEND_INTEGRATION.md)

## 계산 구조와 기반 자료

1. **집계.** 기상 날짜마다 `부족분 = max(0, 목표 − 실제 야간 수면)`을 계산하고 기록된 날의 값을 합한다. 초과 수면과 낮잠은 각각 합산한다. 결측일은 별도로 세고, 사용자가 확인한 밤샘은 실제 야간 수면 0분으로 처리한다. 입력 데이터는 Spring의 사용자별 일별 수면·목표 기록이다. [집계 코드](shortfall.py)
2. **수행 모형.** Ramakrishnan 등의 Unified Model of Performance(UMP), 논문 Table 2의 그룹 계수와 시간에 따른 상태 전이식을 사용한다. 각성 상태의 수면 압력은 `S' = U + (S − U) exp(−t/τwake)`이고, 수면 구간에는 별도 감쇠식을 사용한다. 수행 대리값은 압력에 일주기 조화항을 더한 값이다. UMP의 무차원 상태와 제품의 분 단위 부족 집계는 각각 별도 필드에서 다룬다. [Ramakrishnan 등(2016)](https://doi.org/10.5665/sleep.5358) · [구현과 계수](performance_model.py)
3. **계획.** 성인 확인과 선호 시각, 준비·이동, 일정 충돌을 고려해 기상일별 후보를 만든다. 관측이 완전하면 UMP 평가를 이용하며, 상태를 구성할 수 없으면 부족 구간별 제품 규칙을 적용한다. 기록이 불완전하면 기준 수면 계획과 자료 보완 상태를 돌려준다. 이동 가능 일정은 조건부 확인 요청으로 표시한다. [계획기](planner.py) · [대체 정책](recovery_policy.py)

이 패키지는 팀의 sleep-coach v4 전달본을 바탕으로 하며 논문에 보고된 계수를 실행에 사용한다. 별도로 학습한 개인 회복 파라미터나 원 연구의 참가자 데이터는 패키지에 포함되지 않는다. [원본 전달 README](../../dummy/docs/upstream/sleep-coach-v4-README.md)
