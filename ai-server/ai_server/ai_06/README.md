# AI-06 집중 모드 수면 추천 설계

[계산 흐름도](FLOW.md) · [통합 백엔드 연동](../BACKEND_INTEGRATION.md)

## 구현 공식과 후보 선택

### 1. 후보와 개인 수면량

기준 시각 이후의 15분 격자에서 침대 진입 시각을 정하고, 체류 길이 역시 15분 간격으로 탐색한다. 길이 (T)는 요청한 최소·최대 사이에 있어야 하고, 침대 이탈 시각 `진입 + T`는 기상 마감 이하여야 한다.

- **수면 비율 기준**은 `r = median(실제 수면시간_i / 침대 체류시간_i)`이며, 후보의 실제 수면은 `S_hat = T × r`로 추정한다.
- **개인 Ridge**는 `x = [T, sin(2πh/24), cos(2πh/24), 직전 최대 3개 기록의 평균 수면시간]`을 사용한다. `h`는 취침 시각을 0–24시간으로 표현한 값이다. 표준화한 특징 `z`로 `Σ(S_i − b − β·z_i)² + 10‖β‖²`를 최소화한다. 기록 28건 이상에서 과거 데이터만 순서대로 사용해 평가하고, 평가 10건 이상과 MAE 5% 및 0.1시간 이상 개선을 모두 충족할 때 채택한다. 후보 체류 길이가 기록 범위 밖이거나 가장 가까운 기록의 취침 시각과 1시간 넘게 차이 나면 수면 비율을 사용한다. [개인 수면 추정](personal_sleep.py)
- **잠복기와 비수면 여유**는 별도로 계산한다. 취침 시각 ±1.5시간의 잠복기 기록이 3개 이상이면 그 중앙값, 아니면 전체 관측 잠복기의 중앙값을 사용한다. 총 비수면 여유는 `60 × (T − S_hat)`분이다. 잠복기 자료가 없으면 사용자용 입면 시각은 미상이며, PVT 시각 특징에는 침대 진입을 대리값으로 사용한다. [잠복기 코드](sleep_windows.py) · [플래너](sleep_planner_v1.py)

### 2. PVT 점수

후보의 특징 `x`에는 예상 수면시간, 침대 체류시간, `100 × S_hat / T`로 계산한 수면 효율, 잠복기와 각성 관련 값, 입면·기상 시각의 사인·코사인이 포함된다. 최근 3일·7일의 날짜 창이 모두 채워진 경우에만 각각의 평균과 표준편차를 계산한다. 추가 파생 특징은 `S_hat − 3일 평균`, `S_hat − 7일 평균`, `S_hat + 7 × 7일 평균`이다.

결측 특징은 학습 중앙값으로 보완한다. 동결 모델 `tree3`은 절대오차 손실을 사용하는 히스토그램 그래디언트 부스팅 회귀다. 트리당 최대 잎은 3개, 반복은 100회, 최소 잎 표본은 60개, L2 규제는 10이다. 최종 점수는 `PVT_hat = max(0, tree3(x))`이며 낮을수록 이탈 지표가 낮게 예측된다. 실제로 완료된 수면에서 학습한 관계를 계획 후보의 추정 특징에 적용하는 단계에 전이 가정이 들어간다. [학습·특징 코드](sleep_only_v2.py) · [동결 모델 선택 기록](sleep-only-cognition-v2/selection.json)

### 3. 계획 순위

수면시간·침대 체류시간·수면 효율이 학습 범위를 벗어나거나, 후보 또는 과거 기록에 정오 이후 기상이 포함되면 해당 PVT 예측을 보류한다. 지원 후보가 있으면 `PVT_hat`이 가장 낮은 후보를 고른다. 동점에서는 평소 취침·기상 시각과의 원형 거리 합, 평소 실제 수면시간 중앙값과의 차이, 이른 취침 순으로 비교한다.

지원 후보가 없으면 예상 실수면 분 `m = 60 × S_hat`에 대해 `k = max(1, floor(m/90 + 0.5))`, `오차 = |m − 90k|`를 계산한다. 오차가 가장 작은 후보를 우선하고, 동점은 평소 실제 수면시간과 시각의 가까움으로 푼다. 이 대체안은 팀이 정한 규칙이다. 15분 격자, 잠복기 검색 폭, Ridge 채택 기준도 구현에서 정한 값이다. [플래너](sleep_planner_v1.py)

## 검증 수치의 해석

학습 후보는 참가자 단위 5-fold에서 각 참가자의 MAE를 먼저 구한 뒤 평균한 값으로 비교했다. 동결 산출물의 검증 세트는 91명·1,987행이다. 참가자 평균 MAE는 `tree3` 3.257, 항상 학습 중앙값을 예측하는 기준선 3.282였다. 모델−기준선 MAE 차이의 보고된 95% 신뢰구간은 [−0.137, +0.079]로, 이 검증에서 모델 우위는 확인되지 않았다. 전달본 README의 과거 테스트도 모델 2.930, 중앙값 2.887을 보고한다. 이 통합에서 연구 데이터를 다시 평가하거나 학습하지 않았다. [검증 산출물](sleep-only-cognition-v2/summary.json)

발표에서는 “Chennai 연구의 관측 수면과 PVT 사이의 관계를 회귀로 학습하고, 개인 수면 추정과 시간표 제약을 결합해 후보를 비교했다”고 설명할 수 있다. 오프라인 MAE는 **관측된 수면 이후의 PVT 예측 오차**다. 미래 수면 계획이 집중력을 개선하는지, 개인별 최적 기상 시각을 찾는지는 별도의 검증 질문이다.
